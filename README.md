🚀 What is AdiShop?

AdiShop is a fully functional e-commerce web application that allows users to browse products, manage carts, place orders, and experience a smooth online shopping journey — just like a real production store.

This project was built to demonstrate real-world full-stack development skills.

👤 User Features

🛒 Add / remove items from cart

🚀 Getting Started
1️⃣ Clone the Repository
git clone https://github.com/your-username/AdiShop.git
cd AdiShop

2️⃣ Backend Setup
cd backend
npm install
npm run dev

3️⃣ Frontend Setup
cd frontend
npm install
npm run dev


Open in browser:

http://localhost:5173
